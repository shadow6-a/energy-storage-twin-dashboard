运维值守版 · 组件与视觉规范

面向 7×24 小时强光控制室值守场景的低饱和深蓝工业风组件体系。所有组件遵循四条原则： 信息层级优先于装饰、告警色严格规范（红 / 橙 / 黄 / 绿）、数字等宽对齐；3D 孪生与 2D 面板同一套语义色。 设计基准 1920×1080，输出适配 2K / 4K 拼接屏。

01

设计原则

PRINCIPLES
层级优先

三级信息层级：并网功率 / SOC 等关键量 > 趋势与分布 > 辅助状态。任何光效不得高于文字对比度。

告警即主线

紧急// 重要 / 一般// 提示四级 + 未确认// 已确认// 已闭环// 已抑制四态，状态色全局唯一。

写实工业 3D

孪生场景使用哑光材质与真实比例，禁止赛博发光体；动效仅保留链路流向与告警脉冲。

联动闭环

列表 / 3D / 指标 / 曲线共享选中态；任何点击都有明确的空间或数据范围响应。

色彩系统

点击色块复制

背景四级、描边三级、文本四级；状态色仅用于表达运行与告警语义，禁止作为装饰色使用。主色为低饱和青蓝，3D 场景直接复用同一语义色。

语义色值使用场景
充电#3FB6C9SOC 上升、谷段充电、流入站内的链路流向
放电#DFAB52并网上网、峰段放电、流出链路
正常 / 待机#3EA87B通信正常、设备在线、健康度「优」
提示#D8B24A一般告警、温度接近阈值、健康度「关注」
重要#DF8A2E重要告警、超温阈值 32℃
紧急#E0523F紧急告警、保护动作、健康度「预警」
离线#5B6B7A通信中断、退役 / 检修设备

色彩容错说明（控制室强光 / 偏色工业显示屏// 色弱值守人员的硬性校验项）

校验项要求本方案落实
高亮度环境识别 告警色在 500lux 以上环境光、偏色屏（色温漂移 ±800K）下仍可分辨 四级告警色彼此最小色相差 ≥ 30°，且全部带描边// 底色衬底；关键数值用 #E2EBF5 高对比（对深底对比度 ≥ 12:1），不依赖饱和度辨读
色弱友好（红绿色弱） 红绿色弱人员可区分紧急// 正常语义 紧急红 #E0523F 与正常绿 #3EA87B 明度差显著（L* 相差 ≥ 15），红绿色弱下仍呈「亮暗 vs 暗冷」对比；一般告警走黄系（色弱下不与绿混淆）
禁止单色传信 任何告警语义不得仅靠颜色传递（电力可视化规范要点） 多重编码冗余：颜色++ 形状（信标菱形// 脉冲环）+ 文字标签（lv-tag「紧急」）+ 状态列 + 计数角标，五路信息同源冗余，任一通道失效不丢失语义
降级可辨 灰阶打印 / 黑白抓屏仍可读 四级告警灰阶化后明度阶梯有序（紧急最深++ 脉冲文字标签保留），断连降级态另有水印文字，不依赖色彩判断工具

验收方法：现场用「灰度截图++ 色弱模拟插件」双重抽检台账与 3D 信标，任一格无法仅凭形状/文字区分等级即判不合格。
